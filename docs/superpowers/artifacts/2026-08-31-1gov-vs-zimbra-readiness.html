Feature readiness review

What changes for users when they move off Zimbra

A side-by-side of Zimbra's Modern web client against 1Gov Mail, checked live against the RISA Zimbra instance and against this codebase — so the migration promise to users holds up.

31 August 2026 Reviewed: mail, calendar, contacts, tasks, files, accounts, security, offline, admin

The short version

1Gov Mail already covers the workflows people use in Zimbra every day, and adds three things Zimbra has none of: an AI writing assistant, real-time collaborative documents, and an offline-first mailbox. Nine areas still need work before "you'll lose nothing" is fully true — three are real gaps to build, the rest are Zimbra workflows this app's interface doesn't surface yet, even though the underlying Zimbra account often still supports them.

What users gain that Zimbra never offered

This is the part of the pitch, not just the parity check.

AI writing assistant

Summarize a thread, rewrite a draft's tone, get reply suggestions — in English, French, or Kinyarwanda — with prompt-injection safeguards on by default.

Real-time collaborative docs

Notion-style pages with live multi-person editing, nested hierarchy, and government templates. Zimbra's closest equivalent is a single-user document Zimlet.

Offline-first mailbox

Read, draft, and queue mail with no connection. It syncs the moment the network comes back — already built, not a roadmap item.

Faster mail workflows

Scheduled send, snooze, mute a thread, message templates, and bulk actions — one click, no equivalent found in the live Zimbra account reviewed.

Close these before making the promise

Ordered by how directly each one would be felt as a loss on day one.

1

Blocked / allowed senders

Small, self-contained, and it's the one spam-control habit people will look for immediately.

2

Sessions & device management

The data already exists in the schema — this is a UI gap, not a new subsystem. Matters for security sign-off.

3

Multi-account & persona support

Anyone currently juggling a second identity or a shared departmental inbox in Zimbra will notice this on day one.

4

Calendar & contact sharing, distribution lists

Needed for any team that coordinates schedules or a shared address book today.

5

Structured search

Keyword-only search will feel like a step back for anyone used to Zimbra's filter builder.

6

Admin console

Needed before this runs as an org-wide service rather than a per-user app.

One nuance worth keeping in the messaging: this client sits on top of a real Zimbra account via SOAP. Some "missing" rows above — IMAP/POP access, GAL, out-of-office — aren't gone at the account level; they're just not exposed in this UI yet. Worth confirming with the Zimbra admin which of those the org actually wants surfaced versus retired.
