# AI Email Client Feature Benchmark (as of September 2026)

Research date: 2026-09-03. Sourced from primary vendor documentation (official docs, help centers, release notes, first‑party engineering/security blogs) wherever possible. Third‑party reviews/blogs were used only to locate primary sources or to fill acknowledged gaps, and are marked as such. Vendor docs change frequently — each section's sources are dated at the point of citation where the page exposes a "last updated" date.

## 1. Microsoft 365 Copilot in Outlook

- **Summarization**: "Summary by Copilot" scans an email thread for key points and produces a summary with numbered citations linking back to the source message; also summarizes attached PDF/PowerPoint/Word files. Defaults to the language of the email being summarized. [Summarize an email thread with Copilot in Outlook](https://support.microsoft.com/en-us/office/summarize-an-email-thread-with-copilot-in-outlook-a79873f2-396b-46dc-b852-7fe5947ab640)
- **Compose/draft assistance**: "Draft with Copilot" generates full emails from a prompt; "Coaching by Copilot" reviews a drafted email and suggests improvements to tone, sentiment, and clarity with an "Apply all suggestions" action. [Draft an email message with Copilot in Outlook](https://support.microsoft.com/en-us/office/draft-an-email-message-with-copilot-in-outlook-3eb1d053-89b8-491c-8a6e-746015238d9b); [Get email coaching with Copilot in Outlook](https://support.microsoft.com/en-us/office/get-email-coaching-with-copilot-in-outlook-91a3cd56-1586-4a31-85c7-2eb8cdb02405)
- **Reply suggestions**: Reply drafting is part of "Draft with Copilot"; tone/sentiment/clarity are steerable via Coaching, but no dedicated "reply length slider" is documented — not documented as a discrete control.
- **Inbox digest / prioritize my inbox**: "Prioritize my inbox" assigns High/Normal/Low priority to incoming mail in parallel with delivery, based on thread participants, job titles, and content; shows Copilot's reasoning in the reading pane; users can teach it with plain-language rules ("It's from…", "mentions…"). Only applies to mail received after activation; excludes non-inbox folders, sender-marked-low-importance mail, OOF replies, meeting invites, encrypted mail, NDRs, and quarantined mail. Requires Outlook for Microsoft 365; rolling out gradually. [Prioritize my inbox](https://support.microsoft.com/en-us/outlook/copilot-outlook/prioritize-my-inbox)
- **Chat-with-inbox / NL Q&A**: Copilot Chat in Outlook is content-aware of an open email/thread and can be asked questions about it; broader "Microsoft 365 Copilot (Premium)" grounds answers automatically in Microsoft Graph/Work IQ across mail, files, calendar, and org relationships, plus "Copilot Search" as a universal AI search surface. [What is Microsoft Copilot?](https://learn.microsoft.com/en-us/microsoft-365/copilot/microsoft-365-copilot-overview) (page dated 2026-08-27, retrieved 2026-09-03)
- **Triage/categorization**: Priority tagging (above) is the documented mechanism; no separate "auto-label/category" engine is documented specifically for Outlook mail beyond existing rules/Focused Inbox.
- **Follow-up/commitment tracking**: Not found in Outlook-specific Copilot docs as a discrete "waiting on" feature; Microsoft's 2026 Wave 1 release notes reference emerging "agentic experiences for email and calendar" for follow-ups but no dedicated Outlook feature page was located. [Release Notes for Microsoft 365 Copilot](https://learn.microsoft.com/en-us/microsoft-365/copilot/release-notes) — **treat as roadmap language, not a shipped, documented feature**.
- **AI/semantic search**: "Copilot Search" (Premium tier) is a semantic, AI-powered search across Microsoft 365 apps and connected data sources, backed by semantic indexing of Graph data. [What is Microsoft Copilot?](https://learn.microsoft.com/en-us/microsoft-365/copilot/microsoft-365-copilot-overview)
- **Language support**: Summaries default to the source email's language; UI language can be forced to match Outlook but resets on restart. No published exhaustive language list found for Outlook Copilot specifically (French is supported as a standard Microsoft 365 UI/AI language, per Microsoft's general multilingual Copilot support, but a dedicated Outlook-Copilot language matrix was not located — **gap**).
- **Deployment & privacy model**: Cloud-only (Microsoft Graph + LLM backends); protected under "Enterprise Data Protection" (same contractual commitments as Exchange/SharePoint data), with EU Data Boundary routing for EU tenants (non-EU traffic can route outside the EU). Model options include a Microsoft router plus, in some licensed experiences, Anthropic models as sub-processors, governed by Microsoft's enterprise data protections — **not** a customer-supplied/self-hosted model. [What is Microsoft Copilot?](https://learn.microsoft.com/en-us/microsoft-365/copilot/microsoft-365-copilot-overview). **Government cloud**: Microsoft 365 Copilot (base, including Outlook) reached General Availability in **GCC High** (Dec 2025) and in **DoD IL5**; the most agentic/autonomous capabilities lag or are excluded from sovereign clouds. [Microsoft 365 Copilot is now available in GCC-High](https://techcommunity.microsoft.com/blog/publicsectorblog/microsoft-365-copilot-is-now-available-in-gcc-high/4473310); [Understand Microsoft US government cloud environments for Microsoft 365 and Microsoft Copilot](https://learn.microsoft.com/en-us/microsoft-365/copilot/gov-overview)
- **Prompt-injection / AI-safety measures**: Microsoft documents a "Cross-Prompt Injection Attack (XPIA)" classifier built into Copilot that is meant to detect and block/ignore malicious instructions embedded in grounding data (e.g., a crafted email), and Microsoft Defender now ships out-of-the-box detections for UPIA/XPIA prompt-injection attempts. However, this defense was **bypassed** in the real-world "EchoLeak" zero-click vulnerability (CVE-2025-32711, disclosed June 2025) and a follow-on email-summarization XPIA (CVE-2026-26133) that let attacker-controlled text embedded in an ordinary email hijack Copilot's summary output for phishing — both patched by Microsoft, but they show the classifier is not fully robust against novel techniques. [How Microsoft Defender helps security teams detect prompt injection attacks in Microsoft 365 Copilot](https://techcommunity.microsoft.com/blog/microsoftthreatprotectionblog/how-microsoft-defender-helps-security-teams-detect-prompt-injection-attacks-in-m/4457047); [EchoLeak (CVE-2025-32711) analysis](https://sentra.io/blog/copilot-echoleak-prompt-injection) (third-party security research, not Microsoft primary source, used only to corroborate the vulnerability's existence)
- **Pricing tier**: Outlook draft/summarize/coaching ship in the **Microsoft 365 Copilot (Basic)** add-on tier (no separate Copilot license needed for standard access to in-app features); **Premium** adds Graph/Work IQ grounding, Copilot Search, semantic indexing, Purview controls, and Copilot Cowork agents. Standalone **Copilot Chat (Basic)** (bundled with many M365 SKUs) provides limited Outlook chat using open-content/web grounding only. [What is Microsoft Copilot?](https://learn.microsoft.com/en-us/microsoft-365/copilot/microsoft-365-copilot-overview)

**Confidence & gaps**: Could not find an official, Outlook-specific "waiting-on/follow-up tracking" feature page (only roadmap language). Could not find a definitive, dated language-support matrix specific to Copilot in Outlook (as opposed to Microsoft 365 Copilot generally). Could not confirm whether Anthropic-model routing is available inside GCC High/DoD IL5 Outlook specifically.

## 2. Gmail with Gemini (Google Workspace)

- **Summarization**: "AI Overview for email threads" (branded "Summarize this email" in-product) condenses long threads into key points; also "AI Overview for Gmail search" summarizes search results. [Get started with Google Workspace with Gemini](https://support.google.com/mail/answer/13952129?hl=en)
- **Compose/draft assistance**: "Help me write" composes new emails or refines existing text from a prompt, with rewrite/tone controls (e.g., formalize, elaborate, shorten) exposed in the Gmail compose toolbar. [Get started with Google Workspace with Gemini](https://support.google.com/mail/answer/13952129?hl=en)
- **Reply suggestions**: "Suggested replies" (Smart Reply) offers context-aware quick responses at the end of a thread. [Get started with Google Workspace with Gemini](https://support.google.com/mail/answer/13952129?hl=en) — steerable length/intent controls are not separately documented for Smart Reply; "Help me write" is the tool for steered, longer replies.
- **Inbox digest / prioritize my inbox**: "AI Inbox"/Gemini side panel surfaces top priorities and topics for a quick catch-up. [Get started with Google Workspace with Gemini](https://support.google.com/mail/answer/13952129?hl=en)
- **Chat-with-inbox / NL Q&A**: The Gemini side panel in Gmail lets users ask natural-language questions about their mail with one-click, full-context assistance. [Get started with Google Workspace with Gemini](https://support.google.com/mail/answer/13952129?hl=en)
- **Triage/categorization**: Gmail's long-standing (non-generative) tab/category system (Primary/Social/Promotions) remains the categorization layer; Gemini's contribution is the "AI Inbox" prioritization surfaced above, not a separate ML-labeling feature distinct from that.
- **Follow-up/commitment tracking**: Not documented as a discrete Gemini/Gmail feature in the fetched help content — **not confirmed** in primary sources reviewed.
- **AI/semantic search**: "AI Overview for Gmail search" generates a synthesized answer/summary directly from natural-language search queries over mail. [Get started with Google Workspace with Gemini](https://support.google.com/mail/answer/13952129?hl=en)
- **Language support**: Not exhaustively enumerated in the fetched help article; Google states some features require switching the account/display language if unsupported in the user's region — a definitive language matrix for Gmail-specific Gemini features (vs. Gemini app generally) was **not located** — **gap**. No French-specific or African-language-specific statement found.
- **Deployment & privacy model**: Cloud-only, processed by Google's Gemini models. Google's documentation states enterprise submissions are "not used to train models and are not reviewed by humans," and that Workspace content generated/processed by Gemini "is never shared outside your organization." [Get started with Google Workspace with Gemini](https://support.google.com/mail/answer/13952129?hl=en); [Google Workspace with Gemini overview](https://knowledge.workspace.google.com/admin/generative-ai/workspace-with-gemini/google-workspace-with-gemini). Admins can toggle Gemini access per Workspace service and manage Beta features via the AI Control Center. **Government/compliance**: Google's *Gemini for Government* / *Gemini Enterprise* line supports data residency and FedRAMP High / DoD IL4 (and some IL5) compliance, but this is documented for Google Cloud's Gemini Enterprise Agent Platform, not confirmed as applying to consumer/Workspace **Gmail's** Gemini features specifically — treat as a separate, adjacent Google product line. [Deployment guidance for Gemini for Government](https://docs.cloud.google.com/docs/security/compliance/deploy-gemini-gov); [Data residency | Gemini Enterprise Agent Platform](https://docs.cloud.google.com/gemini-enterprise-agent-platform/resources/data-residency). No customer-hosted/BYO-model option is documented for Gmail's built-in Gemini features.
- **Prompt-injection / AI-safety measures**: Google has published a "layered defense strategy" for indirect prompt injection in Gemini, covering: proprietary prompt-injection content classifiers, "security thought reinforcement" instructions wrapped around prompts, markdown sanitization and URL redaction (via Safe Browsing), a user-confirmation requirement for risky actions (e.g., deleting calendar events), end-user security notifications, and adversarially-trained model resilience (cited as improved in Gemini 2.5). Google's own blog and admin docs acknowledge this is a continuous, evolving effort — implicitly acknowledging prior gaps (e.g., a documented case where hidden white-on-white text in an email body caused Gemini to inject a fake "security alert" into an email summary). [Google Workspace's continuous approach to mitigating indirect prompt injections](https://knowledge.workspace.google.com/admin/security/indirect-prompt-injections-and-googles-layered-defense-strategy-for-gemini) (page dated 2026-08-26, retrieved 2026-09-03); [Mitigating prompt injection attacks with a layered defense strategy](https://blog.google/security/mitigating-prompt-injection-attacks/)
- **Pricing tier**: Gemini in Gmail is included starting at **Business Starter** for Workspace business/enterprise customers; personal Gmail users need a **Google AI Plus/Pro/Ultra** subscription for full access, though "Help me write," Overviews, and suggested replies are noted as free to some personal users in the US. [Get started with Google Workspace with Gemini](https://support.google.com/mail/answer/13952129?hl=en)

**Confidence & gaps**: Could not verify a Gmail-specific follow-up/"waiting on" tracking feature. Could not verify a definitive, current language-support list scoped to Gmail (as opposed to Gemini broadly). Could not confirm whether FedRAMP/IL4/IL5 government compliance extends to the consumer-facing Gmail Gemini features used by an ordinary Workspace tenant, versus only the separate Gemini Enterprise/Cloud product.

## 3. Apple Mail with Apple Intelligence

- **Summarization**: Per-message summaries appear automatically under unread emails in the inbox list; users can also generate on-demand summaries of long/complex threads. [Use Apple Intelligence in Mail on Mac](https://support.apple.com/guide/mac-help/use-apple-intelligence-in-mail-mchlb2dbea8f/mac)
- **Compose/draft assistance**: "Writing Tools" (system-wide, available inside Mail's compose window) can rewrite, proofread, and adjust tone of outgoing messages. [Use Apple Intelligence in Mail on Mac](https://support.apple.com/guide/mac-help/use-apple-intelligence-in-mail-mchlb2dbea8f/mac)
- **Reply suggestions**: "Smart Reply" drafts a fast response intended to "cover everything" raised in the original message; per Apple's June 2026 newsroom release, Smart Reply can now draw on the user's personalized writing style. [Apple Intelligence brings powerful AI capabilities into everyday experiences](https://www.apple.com/newsroom/2026/06/apple-intelligence-brings-powerful-ai-capabilities-into-everyday-experiences/) — explicit length/intent steering controls are not documented as user-facing options; not confirmed.
- **Inbox digest / prioritize my inbox**: "Priority Messages" surfaces the most time-sensitive emails (Apple's example: a same-day dinner invite or a boarding pass) at the top of the inbox; this is Mail's version of an AI triage digest, not a separate daily-briefing product. [Use Apple Intelligence in Mail on Mac](https://support.apple.com/guide/mac-help/use-apple-intelligence-in-mail-mchlb2dbea8f/mac)
- **Chat-with-inbox / NL Q&A**: Not offered. Apple Intelligence in Mail does not expose a conversational "ask your inbox a question" interface in the documented feature set — **not offered / not documented**.
- **Triage/categorization**: Priority Messages functions as the triage mechanism; per Apple's 2026 newsroom post, "Suggestions" in Mail are becoming more capable and can "take action with third-party apps," but a distinct auto-labeling/category engine beyond Priority/VIP/existing Mail rules is **not documented**.
- **Follow-up/commitment tracking**: Not offered / not documented in the reviewed Apple support pages.
- **AI/semantic search**: Not documented as a distinct "semantic search" capability inside Mail search; Apple's on-device Siri/Spotlight semantic index covers system-wide content but a Mail-specific AI search feature page was not found — **not confirmed**.
- **Language support**: Apple Intelligence (system-wide, including Mail's Writing Tools/Summaries) supports English, French, German, Italian, Portuguese (Brazil & Portugal), Spanish, Chinese (Simplified & Traditional), Japanese, Korean, Danish, Dutch, Norwegian, Swedish, Turkish, and Vietnamese; English variants include South African English, but **no Swahili or other African language is supported**. [Apple Intelligence brings powerful AI capabilities into everyday experiences](https://www.apple.com/newsroom/2026/06/apple-intelligence-brings-powerful-ai-capabilities-into-everyday-experiences/); language-list corroborated via multiple 2025–2026 Apple-language-rollout coverage (no single canonical Apple support page enumerating the full current list was captured directly — **partially corroborated, not a single primary citation**).
- **Deployment & privacy model**: Hybrid — Apple's Apple Intelligence architecture runs simple requests on-device and routes more demanding requests to **Private Cloud Compute (PCC)**, Apple's custom-silicon cloud infrastructure that Apple states "uses your data only to fulfill your request, and never stores it," is not accessible even to Apple, and is subject to independent, published cryptographic transparency logs and a public bug-bounty program (up to $1M for remote code execution exploits, up to $250K for data/prompt extraction). [Private Cloud Compute: A new frontier for AI privacy in the cloud](https://security.apple.com/blog/private-cloud-compute/). The Mail-specific support pages do **not** state, per feature, which of Summaries/Smart Reply/Priority Messages runs on-device versus via PCC — **gap**. No enterprise/government-specific data residency or tenant-isolation program is documented for Apple Intelligence in Mail (Apple Intelligence is a consumer/device feature, not sold as an enterprise-configurable service); no customer-controlled/BYO-model option exists.
- **Prompt-injection / AI-safety measures**: No Mail- or email-specific prompt-injection mitigation documentation was located; Apple's public safety messaging for Apple Intelligence centers on PCC's data-minimization and verifiability guarantees rather than published defenses against malicious content embedded in incoming email. **Not documented.**
- **Pricing tier**: Free with a compatible device (Mac, iPhone, iPad) and OS version — Apple Intelligence in Mail is not gated behind a separate paid subscription tier, unlike the other clients in this survey. [Use Apple Intelligence in Mail on Mac](https://support.apple.com/guide/mac-help/use-apple-intelligence-in-mail-mchlb2dbea8f/mac)

**Confidence & gaps**: Could not access Apple's dedicated Apple Intelligence & Privacy legal page directly (404 on the URL attempted); relied on Apple's PCC security-research page instead. Could not find a Mail-specific breakdown of which features are on-device vs. PCC-routed. Could not confirm/deny chat-with-inbox, follow-up tracking, or semantic search as absent with 100% certainty beyond "not found in the documentation reviewed" — Apple's help content is thin compared to Microsoft/Google.

## 4. Superhuman

- **Summarization**: "Auto Summarize" shows a 1-line summary under the subject line for every message, expandable (press `i`) to a more detailed summary. [Auto Summarize – Superhuman Help Center](https://help.superhuman.com/hc/en-us/articles/38458640102291-Auto-Summarize)
- **Compose/draft assistance**: "Auto Drafts" proactively writes full reply drafts in the user's voice for messages that need a response, without being asked; users review/edit before sending. [Auto Reminders & Auto Drafts – Superhuman Help Center](https://help.superhuman.com/hc/en-us/articles/40144492186515-Auto-Reminders-Auto-Drafts) (fetched via search snippet — direct WebFetch was blocked with HTTP 403).
- **Reply suggestions**: "AI Replies" generates on-demand contextual responses; Superhuman's own blog states tone/length adjustments and "translate and fix grammar in multiple languages with a single command" are supported. Superhuman is explicit that "AI never sends messages on its own: final control always remains with the user." [Introducing Superhuman AI](https://blog.superhuman.com/superhuman-ai/)
- **Inbox digest / prioritize my inbox**: Auto Drafts is described as creating "automatic drafts for all pending emails when starting the day," functioning as a de facto daily catch-up mechanism, though Superhuman does not brand a separate "digest" product. [Introducing Superhuman AI](https://blog.superhuman.com/superhuman-ai/)
- **Chat-with-inbox / NL Q&A**: "Ask AI" lets users query their inbox in natural language without recalling sender/keyword/subject, and can combine inbox, calendar, and web data; accessed via Cmd/Ctrl+K → Search or `/`. [Ask AI – Superhuman](https://help.superhuman.com/hc/en-us/articles/38458628979091-Ask-AI)
- **Triage/categorization**: "Auto Labels" automatically categorizes conversations by content, subject, sender, and recipients; "Custom Auto Labels" (Business tier+) let users define their own categories. [Auto Labels – Superhuman Help Center](https://help.superhuman.com/hc/en-us/articles/46005657758861-Auto-Labels)
- **Follow-up/commitment tracking**: "Follow Up Faster" / Auto Reminders identifies emails awaiting a reply and surfaces reminders to nudge the user, paired with Auto Drafts for the response itself. [Follow Up Faster – Superhuman Help Center](https://help.superhuman.com/hc/en-us/articles/45265917418259-Follow-Up-Faster)
- **AI/semantic search**: Ask AI (above) functions as natural-language/semantic search across mail, calendar, and web — not a separately named "semantic search" product.
- **Language support**: Superhuman's non-AI "Autocorrect" feature (desktop only) lists Dutch, English, French, German, Italian, Norwegian, Polish, Portuguese (Brazil/Portugal), Spanish, and Swedish; Superhuman's own blog states its AI "seamlessly operates in Spanish and French." A single canonical list of AI-feature language coverage was not published as a discrete doc page — **partially corroborated**. No African-language support found.
- **Deployment & privacy model**: Cloud-only. Superhuman states neither Superhuman nor its AI vendors train on customer content, data is encrypted in transit and at rest (TLS/AES-256), and agent execution runs in sandboxed environments isolated from core systems and from each other. Superhuman was acquired by **Grammarly** (announced June 30, 2025, closed July 2025) and is now marketed under Grammarly's "Superhuman" brand umbrella alongside Grammarly's writing tool and Coda-derived Superhuman Docs; Grammarly's privacy commitments (no sale/monetization of user content, no third-party model training on content) now apply. [Grammarly to Acquire Superhuman](https://www.grammarly.com/blog/company/grammarly-to-acquire-superhuman/); [Superhuman Agents Privacy and Security Overview](https://support.grammarly.com/hc/en-us/articles/40393024109837-Superhuman-Agents-Privacy-and-Security-Overview). No self-hosted or customer-controlled-model option is documented; Enterprise tier adds SSO and "advanced security and controls" but not on-prem deployment. [Pricing Plans – Superhuman Help Center](https://help.superhuman.com/hc/en-us/articles/38456109456147-Pricing-Plans) (via search snippet, direct fetch blocked)
- **Prompt-injection / AI-safety measures**: No Superhuman-specific published prompt-injection defense documentation was located (unlike Microsoft/Google). The explicit "AI never sends on its own" human-in-the-loop design is the closest documented safety control. **Not documented** beyond that.
- **Pricing tier**: Starter ($25–30/mo) includes "most Superhuman AI features"; **Business** ($40/mo) adds Auto Drafts, Ask AI, and Custom Auto Labels; **Enterprise** (custom pricing) adds SSO and advanced admin controls. [Pricing Plans – Superhuman Help Center](https://help.superhuman.com/hc/en-us/articles/38456109456147-Pricing-Plans)

**Confidence & gaps**: help.superhuman.com blocked direct WebFetch (HTTP 403) for several articles; content above for those pages is reconstructed from WebSearch-provided snippets of the same URLs rather than a full page fetch — treat feature wording as approximate, not verbatim. No canonical AI-feature language matrix found. No prompt-injection-specific documentation found (may simply not be publicly published, not necessarily absent as a control).

## 5. Shortwave

- **Summarization**: "Instant summary" shows the gist of an email or thread in one sentence automatically; AI summaries are also described as reducing time to parse long threads. [The Shortwave AI Assistant](https://www.shortwave.com/docs/guides/ai-assistant/)
- **Compose/draft assistance**: The AI Assistant can write emails, improve drafts, and rephrase; "Ghostwriter" is Shortwave's proprietary technology that learns from a user's past sent mail so drafts "sound like you," including reusing exact phrases; predictive AI autocomplete offers Tab-to-accept inline continuations while composing. [The new Shortwave AI Assistant](https://www.shortwave.com/blog/new-shortwave-ai-email-assistant/)
- **Reply suggestions**: Users can dictate voice/text commands (e.g., "reply to Sarah and suggest Thursday at 2") and the Assistant drafts and queues the reply in Drafts for approval — an instruction-steered, not menu-steered, model (no explicit tone/length slider documented). [The Shortwave AI Assistant](https://www.shortwave.com/docs/guides/ai-assistant/)
- **Inbox digest / prioritize my inbox**: "Smart Bundles" auto-sort newsletters/receipts/notifications; "Inbox Splits" separate messages by importance — together functioning as an always-on prioritization/digest layer rather than a discrete daily briefing product.
- **Chat-with-inbox / NL Q&A**: The AI Assistant "automatically search[es] for emails, calendar events, settings, and other relevant information" to answer natural-language questions, and can chain search + calendar lookup + scheduling + drafting into one multi-step action. [The Shortwave AI Assistant](https://www.shortwave.com/docs/guides/ai-assistant/)
- **Triage/categorization**: Smart Bundles/Inbox Splits (above); "AI Filters" let users write categorization/muting rules in plain English (e.g., "mute anything from a recruiter unless it mentions salary"), with a tier-gated quota (3/10/50 filters on Business/Premier/Max).
- **Follow-up/commitment tracking**: Not explicitly documented as a discrete "waiting on" feature in the sources reviewed — **not confirmed**; the "Tasklet" agent layer (launched Oct 8, 2025) can automate multi-step workflows connecting the inbox to Slack/Notion/Asana/HubSpot, which could cover follow-up automation but is a separate product, not a built-in tracking view.
- **AI/semantic search**: The natural-language query capability described above functions as semantic search across mail + calendar; not separately branded.
- **Language support**: Shortwave's AI Assistant "can... translate text" and reportedly supports French, English, Spanish, and German for the assistant experience — no single canonical, dated language-support doc page was found; treat as approximate. No African-language support documented.
- **Deployment & privacy model**: Cloud-only, built on top of Gmail/Google Workspace accounts. Shortwave states email content is "never used to train third-party AI models and is never shared with anyone outside" its listed sub-processors (Google Cloud, OpenAI, Anthropic, Pinecone), using Retrieval-Augmented Generation (RAG) rather than fine-tuning on user data. Data is AES-256 encrypted at rest and TLS-encrypted in transit; employee access to customer data is audit-logged and requires explicit customer permission. Shortwave follows Google's API Services User Data Policy and undergoes an annual Google-designated third-party security audit; SOC 2 Type II/GDPR support is available on request. [Security & Privacy](https://www.shortwave.com/docs/guides/security/). No self-hosted or customer-controlled-model deployment option is documented; no government/sovereign-cloud program found.
- **Prompt-injection / AI-safety measures**: No Shortwave-specific published prompt-injection defense documentation was located. **Not documented.**
- **Pricing tier**: Business ($30/seat/mo) includes the AI Assistant, summaries, autocomplete, attachment analysis, and web browsing with a capped "Standard intelligence" quota and 3 AI filters; Premier ($45/seat/mo) doubles usage/context and raises the filter cap to 10; Max ($120/seat/mo) further raises usage/context and the filter cap to 50. [Shortwave Pricing](https://www.shortwave.com/pricing/)

**Confidence & gaps**: No canonical, single-page language-support list found. Could not confirm or rule out a dedicated follow-up/"waiting on" tracking UI distinct from Tasklet automation. No prompt-injection safety documentation found (absence noted, not necessarily proof of no mitigation).

## 6. Zoho Mail (Zia)

- **Summarization**: Zia generates a concise summary of an email or thread on request ("Summarize this email chain for me"), offering format choices — a single paragraph, a bulleted list of key points, or a detailed overview — plus options to regenerate, create a task, or add notes from the summary. [Elevate Your Email Experience with Zia](https://www.zoho.com/mail/zia-with-openai.html); [Zia for Mail](https://www.zoho.com/mail/help/zia-artificial-intelligence.html)
- **Compose/draft assistance**: Zia generates new email content from a phrase/idea, with tone adjustment (Formal, Informal, Friendly, Persuasive) and length editing (expand/condense); an auto-suggest/autocomplete-while-typing mode is also documented. [Zia for Mail](https://www.zoho.com/mail/help/zia-artificial-intelligence.html)
- **Reply suggestions**: "Smart auto-reply" / "context-based auto-reply" is documented as a configurable admin-console toggle, generating reply suggestions grounded in the received email's content. [Admin Console - Zia for Mail](https://www.zoho.com/mail/help/adminconsole/zia-for-mail.html) — explicit intent/length steering beyond the tone options above is not separately documented.
- **Inbox digest / prioritize my inbox**: Summarization is positioned by Zoho as helping users "prioritize [their] inbox," but there is no dedicated, separately named daily-digest/briefing feature documented — **not confirmed as a discrete feature**.
- **Chat-with-inbox / NL Q&A**: "Ask Zia" (part of Zoho Workplace) and Zia Search let users query across Zoho Mail (and other Zoho apps — CRM, Docs, Contacts) using natural language, e.g., "Find me emails from a contact." [A new era of AI-powered collaboration: Ask Zia in Zoho Workplace](https://www.zoho.com/blog/workplace/ask-zia.html); [Zia Search](https://www.zoho.com/ziasearch/)
- **Triage/categorization**: Not documented as a distinct ML auto-labeling engine within Zia for Mail specifically (Zoho Mail has traditional filters/folders separate from Zia) — **not confirmed**.
- **Follow-up/commitment tracking**: Zoho Mail has a non-AI "Email Reminders & Follow-ups" feature ([Email Reminders & Follow ups](https://www.zoho.com/mail/help/follow-up-emails.html)); on the CRM side, Zia detects follow-up language ("follow up," "next week") in emails and proactively suggests reminders, and separately predicts "Best Time to Contact" and auto-sets reminders. These CRM-side capabilities are **not confirmed** to be present in Zoho Mail's standalone Zia for Mail feature set — likely CRM-only. [AI features in Zoho CRM](https://www.zoho.com/crm/ai-features-in-zoho-crm.html)

## On-premises / customer-controlled LLM processing — the key differentiator

Across all nine clients researched, **none offers a fully self-hostable, on-premises AI email deployment where a government or enterprise customer runs the entire mail-AI stack (including the LLM) inside its own infrastructure with no vendor cloud dependency for the generative features.** The closest approximations found:

1. **Proton Mail (Scribe) — partial, closest match.** Scribe's **local mode downloads an open-source Mistral 7B model to the end user's own device** and performs compose/rewrite entirely on that device, with Proton stating the data "never leaves it." This is real on-device inference of an open-weight model, but it is (a) **per-device**, not a centrally-managed on-prem server a government IT department controls or updates, (b) **English-only**, forcing non-English users (e.g., French-speaking staff) onto Proton's cloud servers instead, and (c) limited to compose/rewrite — Proton Mail has no AI summarization, triage, chat-with-inbox, or search features at all, on-device or otherwise. Still, it is the only client in this set where an open-source, independently-auditable model genuinely executes outside any vendor's cloud. [Introducing Proton Scribe, a private writing assistant](https://proton.me/blog/proton-scribe-writing-assistant); [How to use the Proton Scribe writing assistant](https://proton.me/support/proton-scribe-writing-assistant)
2. **Canary Mail — on-device triage only, not generative AI.** Triage, categorization, indexing, and local search run on-device and offline, but this is classic on-device ML/heuristics for organization, not LLM-based generation; drafting/summarizing/Q&A still call out to "privacy-controlled cloud AI." No BYO-model support was found. [Private AI Email That Won't Train on Your Data](https://canarymail.io/features/ai)
3. **Zoho Mail (Zia) — BYOK, not self-hosted.** Admins can point Zia at their **own API key** for OpenAI/Gemini/Claude/Cohere ("Bring Your Own Key"), which shifts commercial/billing control to the customer and could in principle be pointed at a private-cloud-hosted endpoint if the chosen provider offers one (e.g., an Azure OpenAI private deployment) — but Zoho's own documentation still describes this as "shared to an external third party," i.e., it is not a mechanism for running the model inside the customer's own network, and Zoho explicitly disclaims responsibility for the resulting data flows. [Admin Console - Zia for Mail](https://www.zoho.com/mail/help/adminconsole/zia-for-mail.html)
4. **Microsoft 365 Copilot — enterprise-grade cloud isolation, not on-prem.** Strong contractual/tenant data-protection guarantees (Enterprise Data Protection, EU Data Boundary) and availability in GCC High/DoD IL5 government clouds, but the LLM inference itself always runs in Microsoft (or, for some licensed experiences, Anthropic-as-subprocessor) cloud infrastructure — never on customer-owned hardware, and no "point Copilot at your own model" option is documented. [What is Microsoft Copilot?](https://learn.microsoft.com/en-us/microsoft-365/copilot/microsoft-365-copilot-overview)
5. **Google Gemini for Government — compliance isolation, not on-prem.** FedRAMP High/IL4/IL5 support via Assured Workloads restricts *where* (which Google-operated region) processing happens and enforces data-residency/organizational policy boundaries, but this is documented for the separate Gemini Enterprise/Cloud product line, not confirmed for Gmail's built-in Gemini features, and in neither case does Google offer customer-hosted inference. [Deployment guidance for Gemini for Government](https://docs.cloud.google.com/docs/security/compliance/deploy-gemini-gov)
6. **Apple Intelligence — Private Cloud Compute, not customer-controlled.** PCC is a strong, independently-verifiable privacy architecture (stateless, no Apple access, published transparency logs, external security research/bounty program), but it is Apple-operated infrastructure that no customer — enterprise or government — can host, audit-and-deploy themselves, or substitute with a different model. [Private Cloud Compute: A new frontier for AI privacy in the cloud](https://security.apple.com/blog/private-cloud-compute/)
7. **Superhuman, Shortwave, Spark — no on-prem or BYO-model option documented at all.** All three are architecturally cloud-only, calling out to vendor-selected third-party model providers (OpenAI, Anthropic, Google Cloud, Azure OpenAI) with no customer choice of model or hosting location beyond the vendor's own sub-processor list. [Security & Privacy (Shortwave)](https://www.shortwave.com/docs/guides/security/); [Spark +AI: security and data](https://sparkmailapp.com/help/spark-ai/spark-ai-security-and-data)

**Implication for a government/self-hosted-model deployment benchmark:** every major commercial email-AI product in this survey is either fully cloud-dependent for generative features, or (Proton's case) offers only a narrow, English-only, per-device local-inference mode with no summarization/triage/search capability at all. A government deployment that runs its own LLM behind its own firewall for full mail-AI functionality (summarization + compose + triage + chat-with-inbox + search) — the kind of architecture implied by "self-hosted model" — is **not matched by any product surveyed**, including the privacy leaders (Proton, Canary). This is the genuine differentiator: none of these vendors let an organization run the *entire* feature set against a model the organization deploys and controls.
