Observations

  • .155 disk is the one real pressure point: 78% full with only 11 GB free, on a box that has been up 216 days accumulating Docker images and three products' databases. If it keeps hosting all three, a cleanup (docker system prune, old images) or a disk grow is worth scheduling.
  • .155 dips into swap (0.8 GiB) — not critical, but consistent with dockerd alone holding 1.4 GiB. .154 touches no swap at all.
  • .154 is the healthier and current deployment: 6.7 GiB RAM available, 34 GB disk free, and running yesterday's build — while .155 still serves a June build, 72 commits behind.
  • Shared credentials: the same password works for test@10.10.94.155 and risa1@10.10.94.154. Fine for an internal test overlay, but worth rotating before anything external-facing.
  • Postgres exposed on .155: docflow's postgres publishes host port 5432 to the network (0.0.0.0:5432); .154 keeps its postgres on localhost only.
