What you can use right now (on .154)

  • Draft doc from a thread: one click above the thread title — the model reads the full bodies of the last 10 messages, picks the best of the 17 gov templates itself, writes the document as sanitized markdown, and opens it in Docs via the new /docs?open=<id> deep link. Cancel works at every step; if you cancel at the very last moment and the doc was already saved, a toast with an Open action tells you instead of leaving a silent orphan.
  • Smart event from mail: all three paths (drop on the calendar, drop on the sidebar, right-click → Create event) open the form instantly and AI-fill title, times, location, and attendee chips from the full email body — but never a field you've already touched, and invites still only go out on your Save. Bonus fix: drag-created events now keep their link back to the source email (both drag paths silently lost it before).
  • Natural-language events: a quick-add box in the calendar toolbar — "Steering committee Tuesday 10–11 with Erick and Tricia" opens the create form prefilled. Unlike task quick-add it never creates directly, because saving sends invites.
  • Format as minutes: select raw notes in a doc → Minutes in the AI row restructures them into Attendees / Agenda / Decisions / Action items with bold owners, with Replace or Insert below — and a prompt that forbids inventing names, decisions, or dates.

The Critical the sweep caught

First deploy's browser sweep froze the page — permanently — the moment a non-empty AI fill landed in the event form (empty fills were fine). Root causes, both fixed in 30eb1c8 and verified by regression tests that genuinely fail on the pre-fix commit: the fill write-back was never idempotent (a fresh attendees array on every merge defeated the change-guard, so every fill committed state churn), and all-day parses wrote bare dates like 2026-09-12 into datetime fields — non-picker-safe and read as UTC midnight on save. The redeployed reproducer now fills cleanly: workshop email → title, Sep 6 18:00 → Sep 9, location "Nyanza", attendees left empty (the no-invention rule), page responsive throughout. Nothing was saved during testing — no test invites went to real people, per your rule, now in standing memory.
