What you can use right now

  • Thread → tasks: the promote arrow on any commitment opens a prefilled, editable task (title, context line, AI-parsed due date from the hint, mail link). Saving records the task against the ledger exactly as before — the endpoint now accepts your edits.
  • Docs writing assistant: select prose → the bubble's AI row: Rewrite (paraphrase / formal / concise / friendly / fix grammar) and Summarize — streamed preview, then Replace selection or Insert below. Collaboration-safe (ranged edits only; the popover closes if the doc changes under it).
  • Natural-language quick-add: tasks page — "chase the TOR from Solange on Friday" becomes a task with a due date; with AI off or unreachable it degrades to a plain title, never blocks.
  • Workload strip: Brief me now opens with exact numbers — open tasks, overdue, due this week, commitments split — no model call, links straight to the sources.

Two bugs the work surfaced

  • ComposeModal rewrites were corrupting their own line breaks (the old escape ordering escaped the <br/> tags it had just inserted). Fixed via the shared textToHtml helper, unit-tested.
  • The new API build script initially shipped without the generated Prisma client — caught as a crash-loop on .155, rolled back inside a minute, fixed (in-bundle prisma generate), tar-verified, redeployed. .154 never went down. The script now lives durably at scripts/build-api.sh.
