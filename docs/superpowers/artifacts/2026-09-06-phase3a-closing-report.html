What lands with the deploy

  • Ask 1Gov, everywhere: one Ask panel mounted app-wide — floating button on every page, the rail on mail — answering from mail + documents + calendar in one fused, cited response. Mail chips open messages, doc chips open docs, event chips open the calendar detail (new ?event= deep link), including when you're already on that page.
  • Doc embeddings with an honest ACL: one set of vectors per document; every query joins through owner-OR-live-invite, so a revoked invite vanishes from answers instantly. The opus reviews hunted for leak paths twice and found none — parenthesization, bound params, email normalization, and the pre-stream access gate all verified.
  • "Ask this document" — a scope chip on the same panel, opened from the docs editor toolbar, removable to widen the same conversation. Fail-closed on anonymous share links.
  • A calendar leg without embeddings: "what do I have with MINIJUST next week?" answers from a deterministic keyword+date lookup over your events.
  • All guardrails travel: per-type fencing (EMAIL/DOCUMENT/EVENT), neutralized headers, citation whitelisting (the model still cannot mint a link), injection banners now source-aware, snippets-only over the wire, no-sources short-circuit in three languages.
